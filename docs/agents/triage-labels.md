# Triage Labels

Skills 使用五个标准 triage 角色。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue  |
| `needs-info`               | `needs-info`         | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完整定义，可交给 AFK agent  |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现            |
| `wontfix`                  | `wontfix`            | 不会处理                     |

当 skill 提到某个角色时（例如"应用 AFK-ready triage 标签"），使用本表中的对应标签字符串。

编辑右列以匹配你实际使用的词表。
